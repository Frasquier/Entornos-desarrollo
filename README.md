# Entornos-desarrollo

//Problema, plataforma y lenguaje elegido:
Hacer un shooter en una plataforma web en html. Seria un juego pvp, con personajes realistas en partidas cerradas 1v1.No habria clases, por lo que cada jugador tendria las mismas estadisticas. El juego seria en 3 persona, con un una tematica animada. Partidas al mejor de 5. Las partidas podrian ser en lan o online. Tendriamos 5 mapas disponibles y 4 armas disponibles en el lanzamiento.

//Algoritmo o ejemplo de paradigma que usarias:
Quiero que cada categoria este separada dentro del codigo para que este mejor organizada. (personajes, mapas, armas, menus, conexiones..)

//Como llega el codigo a ejecutarse:
Se ejecuta directamente en web y habria un lanzador oficial con aplicacion de escritorio que te redigiria directamente a pagina del juego.
